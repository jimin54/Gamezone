🐣 2048 玩法說明

這是經典 2048 的可愛動物版。滑動畫面,所有動物會朝同一個方向移動,兩隻相同的動物碰在一起就會合併,變成下一階的動物。目標是一路合併,合出 🌈 2048。

合併順序

🐣 2 → 🐥 4 → 🐰 8 → 🐱 16 → 🐶 32 → 🦊 64 → 🐼 128 → 🐨 256 → 🦁 512 → 🦄 1024 → 🌈 2048

遊戲規則

  • 每次有效的移動之後,空格裡會冒出一隻新的 🐣 或 🐥。
  • 合併時,會得到「合併後那個數字」的分數。
  • 盤面塞滿,而且沒有任何相鄰的相同動物可以合併時,遊戲結束。
  • 合出 2048 之後可以繼續玩;之後每合出新的最高階動物(4096、8192……)都會有慶祝畫面,並能分享給朋友。

操作方式

  • 電腦:方向鍵或 W、A、S、D。
  • 手機:在棋盤上往上、下、左、右滑動。

小技巧

  • 把最大的動物固定在一個角落,不要輕易把它移走。
  • 盡量只用三個方向(例如下、左、右),少用會把大動物移走的那個方向。
  • 讓數字由大到小排成一列,方便一路連鎖合併。

常見問題

可以超過 2048 嗎? 可以,數字沒有上限,一直玩到盤面塞滿為止。

最高分會保存嗎? 會,記錄在你的瀏覽器裡。清除瀏覽資料或換裝置後紀錄會消失。
